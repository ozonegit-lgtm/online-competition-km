# Manual KM Office fixtures

These are unchanged binary fixtures from Apache POI at commit
`a07e531ec0c729f88ea3e859ecf8b99e13f7317f`, renamed for clarity.
They exercise actual producer-exported OOXML packages, in addition to the
small synthetic packages generated by `KnowledgeItemUploadTest`.

The test also generates valid packages with `docProps/core.xml` and
`docProps/app.xml` before the main Word/PowerPoint part, matching the ordering
found in the failing `test_upload.docx` and `test_upload.pptx`. PHP 8.2.33 Fileinfo
in the app image detects these as `application/octet-stream`, while the earlier
three-part test packages are detected as the specific Office MIME. The generic
fixtures are generated from test-only XML; no user document contents are stored
in this repository.

| Local file | Apache POI source under `test-data/` | Producer recorded in `docProps/app.xml` |
| --- | --- | --- |
| microsoft-word.docx | [document/TestDocument.docx](https://github.com/apache/poi/blob/a07e531ec0c729f88ea3e859ecf8b99e13f7317f/test-data/document/TestDocument.docx) | Microsoft Office Word |
| microsoft-powerpoint.pptx | [slideshow/present1.pptx](https://github.com/apache/poi/blob/a07e531ec0c729f88ea3e859ecf8b99e13f7317f/test-data/slideshow/present1.pptx) | Microsoft Office PowerPoint |
| libreoffice-writer.docx | [document/comment.docx](https://github.com/apache/poi/blob/a07e531ec0c729f88ea3e859ecf8b99e13f7317f/test-data/document/comment.docx) | LibreOffice 6.0.7.3 |
| libreoffice-impress.pptx | [slideshow/bug60993.pptx](https://github.com/apache/poi/blob/a07e531ec0c729f88ea3e859ecf8b99e13f7317f/test-data/slideshow/bug60993.pptx) | LibreOffice 5.3.2.2 |

Upstream `legal/LICENSE` and `legal/NOTICE` are included alongside the files.
Producer labels describe the embedded metadata, not independent certification
of every edit in the fixture's history.

Run the route regression with:

```text
docker compose exec app php artisan test --filter=KnowledgeItemUploadTest
```

For real browser multipart tests, follow
[`tests/Browser/manual-km-upload.README.md`](../../Browser/manual-km-upload.README.md)
and set `MANUAL_KM_FIXTURES_DIR` to this directory.
